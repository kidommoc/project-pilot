# Journey Map Format

A flat-index of all user journeys. Serves as both index and project overview.

## Structure

```markdown
# {Project Name} — Journey Map

## About

{2-3 sentences: what this project does, what problem it solves, who it's for.}

## Journeys

### {Journey Name}

- **ID**: {journey-xxx}
- **File**: `docs/knowledge/journeys/{name}.md`
- **Actors**: {who participates}
- **Description**: {one sentence}

### {Next Journey}
...
```
